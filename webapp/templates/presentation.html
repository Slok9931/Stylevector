01 // motivation

LLMs write in one voice. People don't.

Personalized generation needs a user's writing style — existing approaches pay a steep price for it.

rag.py

Retrieves past examples at inference time. Latency grows with history size; content and style stay entangled.

peft.py

Trains a separate adapter per user. Needs storage and training time for every single person.

style_vector.py

Encodes style as one vector per user. No retrieval, no training, no per-user parameters.

02 // core idea

Style is a diff in activation space

Contrast a user's authentic writing against a style-agnostic rewrite of the same content. The diff between the two, averaged over their history, is their style vector — then it gets added back into generation, no retraining required.

contrast_example.diffview diff
xi: "Can you help me plan a trip?"
−ŷi: "I can help you plan a trip. First, decide on a destination..." # style-agnostic, Mg(x)
+yi: "ooh trip planning!! ok first things first —" # authentic
suℓ = mean( hℓ(x ⊕ y) − hℓ(x ⊕ ŷ) ) # the style vector
▸ reviewer note
No fine-tuning happens here — suℓ is computed once per user from their existing writing samples, then reused at inference. The only thing that changes per generation is which vector gets added, so swapping "who's writing" costs nothing more than a lookup.
03 // method — three stages, four equations

Three stages, four equations

method.py8 lines
def build_style_vector(history):
    y_hat = M_g(x)              # Eq.4 — style-agnostic response
    a_p, a_n = h(x⊕y), h(x⊕y_hat)  # Eq.5 — contrastive activations
    s_u = mean(a_p − a_n)         # Eq.7 — Mean Difference vector
    return s_u
def steer(h, s_u, alpha):
    return h + alpha * s_u        # Eq.11 — steered generation

10 // toward the end-term

Our proposed extension

A single Mean Difference vector may conflate multiple, independent stylistic dimensions — the paper's own stated limitation.

  • Multi-component style vectors — top-k PCA over contrastive differences, instead of a single mean direction.
  • Norm-preserving steering — rescale after steering to prevent the activation-magnitude blow-up the paper's own Fig. 3 shows at high α.
